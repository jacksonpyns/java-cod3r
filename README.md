# ☕ Java COD3R

Repositório desenvolvido durante meus estudos de **Java**, reunindo exercícios, práticas e desafios realizados ao longo do curso de Java da **COD3R Cursos**.

O objetivo deste repositório é registrar minha evolução na linguagem, fortalecer minha **lógica de programação** e praticar conceitos fundamentais do desenvolvimento de software.

---

## 🚀 Sobre o projeto

Este repositório contém uma coleção de exercícios desenvolvidos utilizando **Java** e **Eclipse**, explorando diferentes conceitos da linguagem ao longo do aprendizado.

Mais do que apenas armazenar exercícios, este projeto representa parte da minha evolução na programação e serve como registro prático dos conceitos estudados.

---

## 📚 Conteúdos praticados

Durante o desenvolvimento dos exercícios, foram trabalhados conceitos como:

* ☕ Fundamentos da linguagem Java
* 🧠 Lógica de programação
* 🔢 Variáveis e tipos de dados
* 🔀 Estruturas condicionais
* 🔁 Estruturas de repetição
* 📦 Arrays e Collections
* 🧩 Métodos e funções
* 🏗️ Programação Orientada a Objetos
* 🔐 Encapsulamento
* 🧬 Herança
* 🎭 Polimorfismo
* ⚠️ Tratamento de exceções
* 📁 Manipulação de arquivos
* 🧮 Operações e estruturas de dados
* 🧪 Práticas e desafios de programação

> Os conteúdos podem variar conforme a etapa do curso e os exercícios realizados.
